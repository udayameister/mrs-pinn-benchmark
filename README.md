# MRS–PINN Benchmark Application

A browser-native Physics-Informed Neural Network for Magnetic Resonance
Spectroscopy brain disease classification.

## 🌐 Live Demo
[https://YOUR_USERNAME.github.io/mrs-pinn-benchmark/](https://udayameister.github.io/mrs-pinn-benchmark)

## 🔬 Features
- Synthetic MRS dataset generation (Lorentzian signal model)
- 4-layer PINN training with physics-informed loss (λ = 0.35)
- Real-time training curves and evaluation dashboards
- Single-sample inference with metabolite sliders
- Real data upload (CSV, JSON, TXT, JCAMP-DX)

## 🚀 Run Locally
npm install
npm run dev
